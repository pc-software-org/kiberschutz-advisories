# KIberschutz security advisories

Security advisories published by [KIberschutz](https://kiberblick.de/kiberschutz), the open-source security work of KIberblick.de.

We report vulnerabilities privately to the maintainers first. An advisory lands here only when the project cannot publish one itself, for example because it has been archived and will not ship a fix. For everything else, the maintainers' own advisory is the reference and we link to it.
